# 历史图文库调用

从 [名称目录](catalog.json) 匹配用户点名的资料组，再读取对应manifest.json及图片和完整原文。目录的manifest路径相对于本Skill目录（各包位于 archives/ 下）；图片及指令路径相对于各包目录。公开仓库不含图片，原图需本地放入各包的 assets/。

可运行 `python retrieve.py --name "调用晨光森灵分支"` 或 `python retrieve.py --image 122`，脚本会返回实际图片、原文绝对路径和对应范围，并复核哈希。脚本位于本Skill目录。

取用时同时读取图片与原文，保留原摄影参数。association_scope是配对边界：同组参考和通用模板不是逐图独立指令；不得把视觉关联声称为已证明的原附件消息身份。目录35组包含Skill、分支、变体及模板，不能计成35个独立母Skill。

用户禁止再访问聊天记录查看图片。仅处理本地资料，不保存过程截图，不自动生成、上传、发送图片。用户后续有明确生成请求时再按其授权处理，安装本身不授权生成。
