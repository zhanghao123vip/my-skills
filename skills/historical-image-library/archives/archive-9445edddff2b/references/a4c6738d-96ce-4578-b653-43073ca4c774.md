## 二、Skill核心识别点

### 1）人物设定
- 18–25岁东方少女 / 年轻仙姬
- 面部幼态与清冷感并存
- 鹅蛋脸 / 小脸
- 杏眼或微圆桃花眼，眼神温柔、纯净、略带月光感
- 鼻梁细直
- 唇色淡粉、清透水润
- 肤色冷白、透亮、细腻，发光感皮肤
- 气质：安静、灵动、温柔、像月下精灵

### 2）发型与头饰
- 乌黑长发 / 半盘发 / 高挽古风发髻
- 发丝顺滑，局部有轻微碎发
- 头饰重点：
  - **月牙额饰**
  - **金色桂花元素**
  - **银色枝蔓发冠**
  - **珍珠流苏**
  - **水晶滴坠**
- 发饰整体要有“月宫 + 桂花 + 星尘”的组合感

### 3）服装设定
- 主色：**月白、雾蓝、冰蓝、银白**
- 面料：透明轻纱、叠纱、薄雾感、轻盈反光
- 局部点缀：银线刺绣、浅金刺绣、月纹、花枝纹
- 袖型：大袖、飘带、长披帛、流动感袖摆
- 整体观感：像月光织成的衣服

### 4）宠物元素
- **白兔 / 灵兔**
- 白色绒毛，柔软蓬松
- 琥珀金色或蜜色眼睛
- 体型偏小，依偎在怀里
- 强调陪伴感、依恋感、治愈感

### 5）场景设定
- 夜晚
- 巨大圆月 / 月轮
- 深蓝夜空
- 桂花枝簇拥前景与边框构图
- 空气中有：
  - 发光花瓣
  - 金色微粒
  - 星尘
  - 光斑
- 场景像“月下桂花秘境”或“月宫花园”

### 6）光影特征
- 主光：冷蓝月光
- 辅光：暖金桂花反射光
- 面部有花影投射
- 高光柔和，局部闪烁感强
- 整体通透梦幻，不厚重不脏
- 带微微朦胧滤镜，但主体五官清晰

### 7）构图常见类型
- 近景抱兔半身肖像
- 侧脸安静凝视
