# 示例：《我也卡过 Been There》

第一期。8 个古人站在雨夜的城关下，把自己卡住的那一关唱给台下的现代人听。

- 成片 4 分 15 秒，16:9 1080P
- 阵容：蒲松龄（考不上）、李清照（离婚被议论）、辛弃疾（中年被晾）三段主歌；沙僧、陶渊明、柳永、司马迁、姜子牙快闪
- 歌：Suno 5 段 Extend；画面：MiniMax H3 768P，33 条 + 3 段测试 + 4 条重抽，约 $25.5

`episode.json` 是这一期的完整设定：歌词、5 个 Suno 文件的段落和切点、每条镜头的动作、观众反应镜头的位置。复制到新的期数文件夹，改人物、歌词、镜头就能用；`song.files` 的 `manual_starts`、`song.cuts`、`line_overrides`、`edit.cutaways` 里的秒数都是这一期的歌特有的，新的一期要按自己的歌重新填。

仓库里不放这一期的定妆图、素材和成片（人像不公开）。
