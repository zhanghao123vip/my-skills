# 拉片：拆一条参考视频

## 怎么拆

```
# 每 2 秒一帧，5×4 拼成联系表，一张图看 40 秒
ffmpeg -i ref.mp4 -vf "fps=1/2,scale=400:-2" f_%03d.jpg
ffmpeg -framerate 1 -i f_%03d.jpg -vf tile=5x4 sheet_%02d.jpg
# 歌词和节奏：先转 16k 单声道 wav 再交给 faster-whisper（直接喂 mp4 会被旧版 PyAV 卡住）
ffmpeg -i ref.mp4 -vn -ac 1 -ar 16000 audio16.wav
```

联系表上的字幕基本就是歌词；whisper 用来看每段多长、几秒一句。

## 写进 00_拉片分析.md

1. **它是什么**：一句话说清形式（谁、在哪、对谁唱、核心情绪）
2. **结构时间轴**：段落 / 时间 / 内容 / 镜头
3. **爆点**：为什么会火，一条一句
4. **共情点**：每段让哪类人破防，破防的是哪一下
5. **视觉**：场景、道具、观众、字幕和名字卡的样式
6. **和 skill 的差别**：哪些步骤能直接用，哪些要改

**只学结构和情绪，不搬内容**：参考片用过的人物一个不用，原句和梗一句不用，片名、副歌都重写。

## 多人古人说唱的通用结构（第一期验证过）

| 段落 | 句数 | 约时长 | 作用 |
| --- | --- | --- | --- |
| 冷开场副歌 | 8 | 22 秒 | 前 3 秒就是全员合唱 + 片名，钩子在第一屏 |
| 主歌 1 / 2 / 3 | 各 16 | 各 42 秒 | 负责「哭」：一个人讲透一种处境 |
| 短副歌 ×2 | 各 4 | 各 11 秒 | 把三段主歌隔开，顺便换人上台 |
| 快闪轮唱 | 每人 2 | 每人 6 秒 | 负责「爽」和转发：一句身世 + 一句当代翻译 |
| 桥段 | 2 | 6 秒 | 全场安静，一句金句 |
| 最终副歌 | 8 | 22 秒 | 灯海、全员、镜头升起 |

情绪曲线：苦 → 自嘲 → 释然 → 燃 → 被陪伴。

## 这类视频的爆点（选人写词时逐条对照）

1. **古人身世 = 当代痛点，一一对上**：考不上 ↔ 考研考公；被贬 ↔ 被优化；大器晚成 ↔ 同龄人焦虑
2. **名句翻成大白话**：观众熟悉的诗句突然有了新意思，是最强的破防点
3. **不说教**：态度是「我经历过，我陪你」，不是「你要坚强」
4. **台下坐着现代人**：外卖员、考研生、带孩子的妈妈、中年上班族，反应镜头替屏幕前的人哭
5. **群像 + 名字卡**（「XX aka 外号」），综艺感强，封面好做
6. **至少一位女性主唱**：婚姻、被议论这些共情，男性角色唱不出来
